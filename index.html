GIF 工坊

免费在线制作和编辑 GIF 动图。所有处理都在你的浏览器里完成，文件不会上传到任何服务器。

作者博客：梦祈亦博客

视频转 GIF

支持浏览器能播放的视频（MP4、WebM、MOV 等）。时长越长、尺寸越大，文件越大。

GIF 编辑

一次完成裁剪、缩放、变速和反转。不需要的项保持默认即可。

GIF 拆帧

把 GIF 拆成一张张 PNG 图片，点击缩略图即可单独下载。

图片合成 GIF

添加图片后，可拖动缩略图或点箭头调整播放顺序；第 1 张就是封面（GIF 的第一帧，预览时先显示它）。高度留空时按第一张图片的比例自动计算；图片会等比居中放入画面，空白处填白。

GIF 优化压缩

通过抽帧、缩小尺寸、降低画质来减小体积；也可只保留指定帧范围（剪切）。

给 GIF 加文字

文字会加在每一帧上，带描边，保证在任何背景上都看得清。

GIF 特效

滤镜、翻转和旋转。滤镜类可调强度（Safari 暂不支持滤镜）。

格式转换

支持 GIF、APNG、WebP 动图转为 GIF；GIF 可转为 APNG 或 WebM 视频。解码 APNG 和 WebP 需要最新版 Chrome 或 Edge。
